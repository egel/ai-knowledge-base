# Welcome to my AI Knowledge Base 👋

This site collects everything useful I learn about **creating stuff with AI** —
prompts, tools, workflows, code snippets and lessons learned.

## How it's organized

| Section       | What goes here                                                        |
| ------------- | --------------------------------------------------------------------- |
| **Prompting** | Prompt techniques, patterns and examples that work                    |
| **Tools**     | Notes on AI tools, models and services                                |
| **Workflows** | End-to-end recipes: how to build X with AI step by step               |
| **Gotchas**   | Pitfalls, limitations and things that surprised me                    |
| **Blog**      | Longer write-ups and experiments                                      |

## Contributing a note

1. Create a Markdown file in `docs/` (or a subfolder, e.g. `docs/prompting/`).
2. Add front matter:

```md
---
title: My shiny note
sidebar_position: 2
---
```

3. Write in Markdown — code blocks, admonitions and diagrams (Mermaid) all work:

```md
:::tip
Admonitions like this render nicely.
:::
```

4. Run `npm run start` and check it locally.
